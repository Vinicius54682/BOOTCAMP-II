🎮 Pokédex — Bootcamp II

Projeto desenvolvido durante o Bootcamp II, com o objetivo de criar uma aplicação web capaz de consultar informações de Pokémon utilizando uma API externa.

A aplicação permite pesquisar Pokémon pelo nome ou número, além de oferecer botões de exemplo para facilitar a interação com o usuário.

📋 Sobre o projeto

A Pokédex utiliza a PokéAPI para realizar requisições assíncronas e obter os dados dos Pokémon em formato JSON.

Após a consulta, as informações recebidas da API são processadas pelo JavaScript e apresentadas na interface de forma organizada.

⚙️ Funcionalidades
🔎 Pesquisa de Pokémon pelo nome.
🔢 Pesquisa de Pokémon pelo número da Pokédex.
⚡ Consulta assíncrona utilizando JavaScript.
🎲 Consulta de Pokémon através dos botões de exemplo.
🧹 Botão para limpar o resultado da pesquisa.
❌ Tratamento de Pokémon não encontrado.
📱 Interface simples e organizada.
🌐 Aplicação publicada através do GitHub Pages.
🔌 API utilizada

O projeto utiliza a PokéAPI, uma API pública que fornece informações sobre Pokémon.

🔗 https://pokeapi.co/

Os dados são obtidos através de requisições HTTP e retornados em formato JSON.

📊 Informações exibidas

Após realizar uma consulta, a aplicação apresenta informações do Pokémon obtidas através da API, como:

Nome
Número na Pokédex
Imagem
Tipo
Outras informações disponíveis no retorno da API

🚀 Como executar o projeto
Opção 1 — Acessar a versão online

Acesse diretamente:

https://vinicius54682.github.io/BOOTCAMP-II/

Opção 2 — Executar localmente
Clone o repositório:
git clone https://github.com/Vinicius54682/BOOTCAMP-II.git
Entre na pasta do projeto:
cd BOOTCAMP-II
Abra o arquivo index.html no navegador.

Também é possível utilizar uma extensão como o Live Server no Visual Studio Code para executar o projeto localmente.
